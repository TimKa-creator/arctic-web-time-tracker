🕒 Arctic Web Time Tracker
Професійна Full-stack система для обліку робочого часу, розроблена з дотриманням принципів чистої архітектури та сучасних стандартів веб-розробки.

🚀 Основні можливості
Global Timer Header: Активний таймер завжди доступний у верхній частині сторінки для швидкого керування.

Smart Task Input: Поле введення назви задачі з функцією автодоповнення на основі попередніх записів.

Project Management: Система управління проєктами з можливістю присвоєння унікальних кольорів для візуальної ідентифікації.

Today's Overview: Групування записів за проєктами з автоматичним підрахунком загального часу за день.

Advanced Reports: Перегляд статистики за день, тиждень або місяць із візуалізацією даних.

Data Export: Можливість вивантаження звітів у форматі CSV для подальшого аналізу.

🏗️ Архітектура (Clean Architecture)
Проєкт структурований за принципом розділення відповідальності (Separation of Concerns), що забезпечує масштабованість та легкість підтримки:

📂 client/ — Presentation Layer: UI-компоненти (Shadcn UI), сторінки та стилі.

📂 server/ — Infrastructure Layer: API-роути, логіка сервера та взаємодія з базою даних.

📂 shared/ — Domain Layer: Спільні типи даних та схеми валідації (Zod), що використовуються на фронтенді та бекенді.

📂 hooks/ — Application Logic: Кастомні React-хуки для керування станом таймера та даними.

🛠️ Технологічний стек
Frontend: Next.js (App Router), React, TailwindCSS.

UI Components: Shadcn UI, Lucide Icons.

Database & ORM: PostgreSQL (Replit/Neon), Drizzle ORM.

Validation: Zod (з використанням z.coerce для надійного парсингу дат).

🚦 Як запустити проєкт
Клонування репозиторію:

Bash
git clone https://github.com/TimKa-creator/arctic-web-time-tracker.git
cd arctic-web-time-tracker
Встановлення залежностей:

Bash
npm install
Налаштування середовища:
Створіть файл .env у корені проєкту та додайте посилання на базу даних:

Фрагмент коду
DATABASE_URL="your_postgresql_connection_string"
Синхронізація бази даних:

Bash
npx drizzle-kit push
Запуск у режимі розробки:

Bash
npm run dev
🛡️ Валідація та Edge Cases
У проєкті реалізовано захист від типових помилок:

Future Time Prevention: Система блокує можливість створення записів із часом у майбутньому.

NaN Protection: Надійна логіка обчислення тривалості, що запобігає виведенню некоректних значень у таймері.

Persistence: Стан активного таймера зберігається в базі даних та відновлюється після оновлення сторінки.
