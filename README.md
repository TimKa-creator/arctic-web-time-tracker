# 🕒 Arctic Web Time Tracker

Професійна Full-stack система для обліку робочого часу, розроблена з фокусом на продуктивність, точність даних та чисту архітектуру.

## 🚀 Основні можливості

* **Global Timer Header**: Активний таймер завжди доступний у верхній частині сторінки для миттєвого керування процесом.
* **Smart Task Input**: Поле введення назви задачі з інтелектуальним автодоповненням на основі вашої історії.
* **Project Management**: Гнучке управління проєктами з колірним маркуванням для швидкої візуальної навігації.
* **Today's Overview**: Групування активностей за проєктами з автоматичним підрахунком сумарного часу.
* **Advanced Reports**: Аналітика за день, тиждень або місяць із детальною розбивкою.
* **Data Export**: Нативний експорт звітів у формат CSV для подальшої обробки в Excel або Google Sheets.

## 🏗️ Архітектура (Clean Architecture)

Проєкт реалізовано з чітким розділенням шарів (Separation of Concerns), що відповідає стандартам корпоративної розробки:

* **📂 client/** — Presentation Layer: Модульні компоненти на базі Shadcn UI та React-сторінки.
* **📂 server/** — Infrastructure Layer: Серверна логіка на Express/Next API з надійними роутами.
* **📂 shared/** — Domain Layer: Спільні схеми валідації та інтерфейси типів, що гарантують Type Safety.
* **📂 hooks/** — Application Logic: Кастомні хуки для ізоляції бізнес-логіки таймера від інтерфейсу.

## 🛠️ Технологічний стек

* **Frontend**: Next.js (App Router), React, TailwindCSS.
* **Backend**: Node.js, Next API Routes.
* **Database & ORM**: PostgreSQL (через Drizzle ORM) — забезпечує цілісність даних та високу швидкість запитів.
* **Validation**: Zod (використання `z.coerce` для запобігання помилкам парсингу дат).

## ⚙️ Встановлення та запуск

1. **Клонуйте репозиторій**:
   ```bash
   git clone https://github.com/TimKa-creator/arctic-web-time-tracker.git
   cd arctic-web-time-tracker
   ```

2. **Встановіть залежності**:
   ```bash
   npm install
   ```

3. **Налаштуйте змінні оточення**:
   Створіть файл `.env` та додайте посилання на вашу базу даних:
   ```env
   DATABASE_URL="your_postgresql_url"
   ```

4. **Підготуйте базу даних**:
   ```bash
   npx drizzle-kit push
   ```

5. **Запустіть додаток**:
   ```bash
   npm run dev
   ```

## 🛡️ Оптимізація та валідація

* **Future Time Protection**: Реалізовано серверний та клієнтський захист від встановлення часу в майбутньому.
* **NaN-Safety**: Використання надійних методів обчислення тривалості (Duration), що виключає появу помилок у UI.
* **Synchronization**: Повна синхронізація стану таймера між сервером та клієнтом навіть після оновлення сторінки.
